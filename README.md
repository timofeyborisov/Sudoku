# Sudoku

Учебный проект на Haskell: настольное приложение для игры в судоку с графическим интерфейсом на базе `Gloss`.

Программа поддерживает:
- главное меню и несколько экранов интерфейса;
- выбор сложности `Easy / Medium / Hard`;
- выбор конкретной головоломки;
- случайную загрузку готового уровня;
- псевдогенерацию новых уровней;
- подсказки;
- автоматическое решение;
- светлую и тёмную темы;
- визуальные подсветки, анимации и иконки интерфейса.

## Возможности

В приложении реализованы следующие функции:

- выбор заранее подготовленных уровней по сложности;
- генерация новых головоломок на основе базовых шаблонов;
- проверка корректности пользовательских ходов;
- запрет изменения исходных клеток;
- подсветка конфликтов;
- подсветка выбранной клетки, её строки, столбца и блока `3x3`;
- подсказка следующего хода;
- автоматическое решение судоку;
- переключение светлой и тёмной темы;
- сброс текущего уровня.


## Запуск проекта

### Сборка

```bash
cabal build
```

### Запуск

```bash
cabal run
```

## Архитектура проекта

Проект разделён на модули
- Main.hs - точка входа;
- Assets.hs - подключение изображений иконок;
- Board.hs - реализация правил игры;
- Config.hs - константы для интерфейса и логики;
- Events.hs - обработка событий в программе;
- Generator.hs - запуск автоматического генератора новых уровней;
- Levels.hs - загрузка встроенных уровней;
- Solver.hs - автоматический запуск различных стратегий решения;
- Types.hs - основные типы данных в программе;
- UI.hs - отрисовка интерфейса.
